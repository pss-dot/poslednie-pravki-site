# Последние правки — блог почтового ящика издательства

Статичный сайт на Astro. Каждый пост — «письмо», которое как будто пришло на
рабочую почту издательского агентства «Последние правки».

## Структура

```
src/
  content/posts/*.md   — сами письма (посты)
  content.config.ts     — схема полей поста
  layouts/Base.astro    — общий каркас страницы (шапка, папки, футер)
  pages/
    index.astro          — «Входящие»: список всех писем
    tag/[tag].astro       — вид по папке (рассылка / авторы / переписка)
    letter/[...slug].astro — открытое письмо
  styles/global.css      — вся стилистика в одном файле
```

## Как устроен один пост

Файл `src/content/posts/название-файла.md`:

```md
---
subject: "Тема письма"
from: "Имя Фамилия <email@example.com>"
to: "info@poslednie-pravki.ru"   # можно не указывать, есть значение по умолчанию
date: 2026-08-01
tag: "рассылка"        # рассылка | авторы | переписка
thread: false            # true — добавит "Re:" перед темой
draft: false             # true — пост собирается, но никому не показывается
---
Текст письма. Можно с пустыми строками между абзацами — переносы сохраняются.
```

Имя файла становится частью адреса письма (`/letter/имя-файла/»), поэтому
пишите его латиницей и через дефис.

## Команды

```bash
npm install       # один раз, после скачивания проекта
npm run dev       # локальный просмотр на http://localhost:4321
npm run build     # собрать статику в папку dist/
npm run preview   # проверить уже собранную dist/ локально
```

## Как выкладывать на Beget

1. `npm run build` — получаете папку `dist/`, это и есть весь сайт.
2. Заходите в панель Beget → Файловый менеджер → папка сайта (`public_html`).
3. **Сделайте бэкап** текущего содержимого `public_html` (там сейчас WordPress) —
   на случай, если что-то захочется вернуть.
4. Очищаете `public_html` и загружаете туда всё содержимое `dist/` (не саму
   папку `dist`, а её содержимое — `index.html`, `_astro/`, `letter/` и т.д.).
5. Готово — сайт статический, никакого Node.js на сервере не требуется.

Если захотите позже автоматизировать этот шаг (пуш в git → сайт сам
обновляется на Beget), это можно настроить через GitHub Actions и FTP-деплой —
скажите, помогу настроить.

## Рабочий процесс с письмами

1. Обсуждаем сюжеты/темы для новых писем (по веткам: рассылка, авторы, переписка).
2. Утверждённые сюжеты превращаются в черновики `.md`-файлов в `src/content/posts/`.
3. Правите текст, тон, детали — прямо в файле или через правки в диалоге.
4. `npm run build` → загрузка `dist/` на хостинг.
